# Video Heartbeat SDK (1.x)

> **Deprecated.** This SDK is no longer supported. For current implementations, use the [Adobe Experience Platform Media SDK](https://developer.adobe.com/client-sdks/home/) or the [Edge Network implementation](https://experienceleague.adobe.com/docs/media-analytics/using/implementation/edge/implementation-edge.html).
>
> The 2.x Media SDK (successor to this library) is available at [Adobe-Marketing-Cloud/media-sdks](https://github.com/Adobe-Marketing-Cloud/media-sdks).

The Video Heartbeat Library (VHL) was the original Adobe media tracking SDK. Starting with v2.2,
it was renamed Media SDK. See the [1.x to 2.x migration guide](https://github.com/Adobe-Marketing-Cloud/media-sdks/blob/master/docs/migration/1x-to-2x.md) for a full API comparison.
